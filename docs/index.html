Criterio de selección

ARIMA(4,1,1) y SARIMA presentaron el menor MAE de validación. El mejor SARIMA fue SARIMA(4,1,1)x(0,0,0,7), por lo que los componentes estacionales adicionales no mejoraron el resultado. Se seleccionó ARIMA(4,1,1) por simplicidad.

La selección del modelo se realizó con 2023. El test de 2024 se reservó para evaluar posteriormente el modelo seleccionado sobre datos no utilizados durante la selección.

Criterio de seleccion

El criterio principal de seleccion fue el MAE sobre los datos de validacion de 2023. Un MAE menor representa un menor error promedio de prediccion. ARIMA(4,1,1) presento el mejor desempeno y por ello fue seleccionado para la evaluacion final de 2024.

La seleccion del modelo se realizo con 2023. El test de 2024 se reservo para evaluar posteriormente el modelo seleccionado sobre datos no utilizados durante la seleccion.
